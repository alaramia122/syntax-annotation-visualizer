# Тестирование

Тесты добавляются вместе с функциональностью. Целевые уровни: модульный, интеграционный и сквозной.

Минимальные группы:
- разбор JSON и структурная валидация;
- семантическая валидация и ссылки;
- координаты Unicode и соответствие исходному тексту;
- поиск по словоформе и лемме;
- карточка слова;
- безопасный вывод пользовательского текста;
- веб-маршруты и ошибки загрузки;
- отказ/недоступность словарного источника.

До появления тестируемого кода эти проверки не считаются выполненными.
