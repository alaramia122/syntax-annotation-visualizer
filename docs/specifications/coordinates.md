# Координатная система

**Статус:** требование из ТЗ зафиксировано; детали должны быть согласованы с полной спецификацией и проверены тестами.

ТЗ устанавливает для первой версии целочисленные смещения в Unicode-кодовых точках Python (`unicode_codepoints`).

## Обязательные свойства

- Диапазоны должны быть однозначными и иметь документированную семантику границ.
- Смещения относятся к исходной строке, а не к строке, восстановленной из токенов.
- Необходимо проверять допустимость диапазонов и соответствие токена указанному фрагменту текста.
- Следует отдельно проверять символы вне базовой многоязычной плоскости, комбинируемые знаки, русские буквы, пунктуацию и переносы строк.
- Если интерфейс использует JavaScript, необходимо учитывать, что индексы JavaScript-строк считаются в UTF-16 code units, тогда как координаты ТЗ — Unicode code points. Преобразование должно быть явным и протестированным.

## Решение, требующее фиксации

До утверждения контракта необходимо окончательно зафиксировать, что диапазон полуоткрытый `[start, end)` (включает start, не включает end), и определить правила для нулевой длины. Это согласуется с распространённым индексированием Python, но должно быть закреплено как решение проекта, а не предполагаться молча.
