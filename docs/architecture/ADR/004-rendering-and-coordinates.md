# ADR-004. Координаты и подчёркивание ролей

**Статус:** принято  
**Дата:** 2026-10-17  
**Уточнение:** 2026-10-17 — линии приведены к школьным обозначениям членов предложения

## Контекст

В JSON-контракте смещения заданы в кодовых точках Юникода. В браузере индексы строки считаются в единицах UTF-16. У токена не больше одной роли; пересечение диапазонов токенов запрещено проверкой. По заданию роли показывают **линиями под словами**, а не заливкой и не стрелками зависимостей.

В русской школе при разборе предложения по членам приняты устойчивые виды подчёркивания. Их и берём за основу, чтобы легенда была узнаваемой.

## Варианты

1. Сервер отдаёт исходные координаты. Клиент один раз строит таблицу «кодовая точка → индекс UTF-16» и режет ею текст.
2. Сервер заранее переводит координаты в UTF-16 и меняет контракт для браузера.
3. Рисовать связи по полю «вершина» (`head`) или несколько линий на одном диапазоне.

## Решение

Принят вариант 1. Пересчёт координат живёт только на клиенте. Сервер не отдаёт второй набор индексов.

На один токен — одна линия. Соответствие **школьным** обозначениям:

| Роль в разметке | Член предложения | Подчёркивание |
|---|---|---|
| `SUBJECT`, `ПОДЛЕЖАЩЕЕ` | подлежащее | одна сплошная линия |
| `PREDICATE`, `СКАЗУЕМОЕ` | сказуемое | две сплошные линии |
| `DEFINITION`, `ATTRIBUTE`, `ОПРЕДЕЛЕНИЕ` | определение | волнистая линия |
| `OBJECT`, `ДОПОЛНЕНИЕ` | дополнение | штриховая линия |
| `ADVERBIAL`, `ADVERBIAL_MODIFIER`, `ОБСТОЯТЕЛЬСТВО` | обстоятельство | штрихпунктир (тире–точка) |
| любое другое непустое значение | — | нейтральная сплошная, серая |
| роль отсутствует | — | линии нет |

Цвет линии только помогает различать роли и **не заменяет** форму линии. Палитра: `#315d80`, `#6b3f2a`, `#3d6b4f`, `#6a4a78`, `#8a5a2b`, нейтральный `#5c6770`. Неизвестная роль не подменяется одной из пяти школьных. В легенде — пять членов предложения и пункт «Другая роль».

Заливка слова цветом роли не используется. Подсветка выбранного слова — отдельное состояние интерфейса. Связи зависимостей в первую версию не входят.

Ограничение среды: у стандартного подчёркивания в CSS нет готового стиля «тире–точка». Для обстоятельства линия рисуется фоновым повторяющимся узором, визуально близким к школьному штрихпунктиру.

## Последствия

Накладывать несколько линий на один диапазон не нужно: корректный документ этого не содержит. Реализация: `static/app.css`, `static/app.js`, легенда в шаблоне.
