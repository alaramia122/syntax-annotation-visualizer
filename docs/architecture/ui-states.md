# Состояния интерфейса

**Статус:** целевая модель этапа 2.  
**Дата:** 2026-10-17

Экран один. Сверху загрузка, ниже текст и карточка. На узкой ширине карточка уходит под текст. Демонстрационный документ открывается при первом заходе, без загрузки файла.

## Страница документа

| Состояние | Что видно | Чего нет |
|---|---|---|
| Демонстрация | `examples/valid/01-basic.json`, бейдж полноты разметки, текст, легенда, пустая карточка | имени файла и списка ошибок |
| Файл принят | то же для загруженного документа и имя файла | списка ошибок и предыдущего документа |
| Пустой принятый документ | панель текста пуста, подсказка выбрать слово | ошибки: пустой контракт v1.0 законен |
| Файл отклонён | заголовок «Документ не принят» и список причин | текста, карточки и предыдущего документа |

Выбор слова не меняет документ и не требует новой загрузки страницы.

## Ошибки загрузки

Сообщение понятно без трассировки. Где можно, в тексте есть путь поля.

| Ситуация | Ответ | Текст |
|---|---|---|
| Файл не выбран | 400 | выбрать JSON-файл |
| Не UTF-8 или не JSON | 400 | не удалось прочитать JSON, с причиной разбора |
| Больше 2 МиБ | 413 | превышен размер 2 МиБ |
| Схема или семантика | 422 | путь и сообщение каждой ошибки |
| Сбой справочника | не ошибка страницы | только блок справки в карточке |

## Карточка

Пока слово не выбрано, видна подсказка «Выберите слово в тексте». После выбора:

- словоформа из `text[start:end]`, без обрезки пробелов по краям, если они всё же входят в диапазон пунктуации;
- лемма, часть речи, роль, отношение и признаки — только если поле есть; иначе «не указано», не догадка;
- употребления по точной словоформе, без учёта регистра и без отбрасывания знаков;
- употребления по лемме: обе стороны сравниваются через `str.casefold()`; для кириллицы это совпадает с переводом в нижний регистр, `ё` и `е` не склеиваются;
- если леммы у выбранного слова нет, поиск по лемме не выполняется и пишется «Лемма в разметке отсутствует»;
- в списках нет выбранного токена; пустой список даёт «Других употреблений нет»;
- группа — отдельный блок с именем роли как в разметке; отсутствующая роль — группа «Роль не указана»; порядок групп и элементов — порядок первых вхождений в документе;
- переход выбирает этот токен и прокручивает к нему;
- справка — последний блок. До подключения адаптера: «Словарный источник не подключён». При отказе: «Справка временно недоступна». Ссылка на внешний поиск, если адаптер её дал, не называется словарной статьёй.

Текущий `static/app.js` уже открывает карточку и ищет совпадения, но не группирует их по ролям и при отсутствии леммы пишет «Совпадений нет». Это предварительное поведение, не принятая реализация этапов 6–7.
