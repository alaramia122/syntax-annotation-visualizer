## Критерий этапа 10

План: обязательные проверки пройдены, ограничения документированы.

Проверено 2026-10-17 (`tests/test_quality.py` + прежний набор):

- Клиентский `app.js` не использует `innerHTML` / `outerHTML` для пользовательских строк.
- Текст с фрагментом `<script>…</script>` принимается как данные; в HTML-ответе сырой тег не появляется (`tojson`).
- Все невалидные фикстуры через `POST /upload` → 400/422 без встроенного документа.
- Unicode / non-BMP / переносы / неизвестная роль — принимаются.
- Документ с текстом 10 000 кодовых точек проходит `load_bytes` быстрее 5 с (ориентир ТЗ, не жёсткий SLA).
- Превышение 2 МиБ → 413 до разбора JSON.
- Лишнее корневое поле → 422 (схема без `additionalProperties`).
- Регрессия: ≥11 валидных и ≥18 невалидных фикстур.
- `python3 -m pytest -q` — **62 passed**.
