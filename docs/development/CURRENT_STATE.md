## Текущий этап по плану

**Этап 1 — анализ требований и формализация входных данных.**

До реализации необходимо зафиксировать:
- точную структуру JSON и обязательность полей;
- модель документа, предложений и токенов;
- систему координат и поведение на Unicode;
- правила ссылок между токенами и синтаксическими отношениями;
- правила обработки неполной разметки и неизвестных ролей;
- JSON Schema, семантические проверки и набор корректных/ошибочных примеров.
