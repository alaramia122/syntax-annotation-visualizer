## Первичная модель данных

- Корневые поля: `schema_version`, `document`, `analysis`.
- `document`: `id`, `language`, `text`.
- `analysis`: `status` (`complete` или `partial`), необязательные метаданные `analyzer`, списки `sentences` и `tokens`.
- Токен: `id`, координаты `start`/`end`, `kind`, `sentence_id`; необязательные `lemma`, `pos`, `features`, `syntax`.
- Координаты — полуоткрытые интервалы Unicode-кодовых точек Python; JavaScript требует учитывать UTF-16.
- Неизвестные значения синтаксических ролей не отбрасываются и не интерпретируются догадками.
