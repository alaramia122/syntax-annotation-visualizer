# Типичные сообщения и ошибки

## При загрузке файла

| Ситуация | Что видно | Что сделать |
|----------|-----------|-------------|
| Файл не выбран | «Выберите JSON-файл для загрузки.» | Укажите файл и повторите отправку |
| Больше 2 МиБ | сообщение о превышении размера (ответ 413) | Уменьшите файл или разбейте документ |
| Не UTF-8 или битый JSON | сообщение о чтении JSON в UTF-8 | Сохраните файл в UTF-8, проверьте синтаксис JSON |
| Корень не объект | «Корневое значение JSON должно быть объектом.» | Корень должен быть `{ ... }` |
| Ошибка схемы | путь поля и текст проверки (код 422) | Сверьте с [форматом](../specifications/input-format.md) и схемой `schemas/annotation.schema.json` |
| Ошибка семантики | путь и текст (диапазоны, id, head и т.д.) | См. [правила валидации](../specifications/validation-rules.md); примеры отказа — `examples/invalid/` |

После отказа предыдущий документ **не остаётся** на странице: видна только форма и список ошибок.

## В интерфейсе разметки

| Подпись | Значение |
|---------|----------|
| «не указано» | В разметке нет значения для этого поля |
| «Лемма в разметке отсутствует» | Поиск по лемме недоступен для выбранного слова |
| «Других употреблений нет» | В документе нет других совпадений (кроме текущего слова) |
| «Роль не указана» | Группа употреблений без синтаксической роли |
| «Загрузка справки…» | Идёт запрос к словарю |
| «Справка временно недоступна» | Источник не ответил или статьи нет; можно открыть внешний поиск |
| «Словарный источник не подключён» | Режим, когда адаптер справки не настроен (в текущей сборке обычно не используется) |

## Запуск и окружение

| Проблема | Что проверить |
|----------|----------------|
| `ModuleNotFoundError` | Активировано ли виртуальное окружение; выполнен ли `pip install -r requirements.txt` |
| Порт занят | Другой процесс на 5000; завершите его или измените запуск Flask |
| Пустая страница / нет линий | В консоли браузера ошибки JS; загружен ли документ (блок текста после успешной проверки) |
| Справка всегда недоступна | Доступ в интернет с машины, где запущен сервер; блокировки к `ru.wiktionary.org` |

Автотесты не заменяют просмотр в браузере, но подтверждают загрузку, проверки и основные HTTP-сценарии:

```bash
python -m pytest -q
```
