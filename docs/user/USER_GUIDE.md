# Руководство пользователя

Приложение показывает **готовую** синтаксическую разметку русского текста: линии ролей, карточку слова, другие употребления и краткую словарную справку. Самостоятельный разбор предложения программа не выполняет.

## Установка и запуск

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/alaramia122/syntax-annotation-visualizer.git
cd syntax-annotation-visualizer
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

Откройте в браузере: `http://127.0.0.1:5000/`.

Остановка: `Ctrl+C` в терминале.

Проверка автотестами (из корня репозитория, с активированным окружением):

```bash
python -m pytest -q
```

## Первый экран

При открытии сразу загружается демонстрационный документ. Видны:

- форма загрузки JSON;
- текст с подчёркиваниями ролей и легендой;
- боковая панель «Карточка слова» (пока без выбранного слова).

## Загрузка своего файла

1. Нажмите «Выберите файл» и укажите JSON в формате проекта (см. [формат входных данных](../specifications/input-format.md)).
2. Нажмите «Загрузить и проверить».
3. При успехе отображаются имя файла и разметка.
4. При ошибке текст и карточка скрываются; показывается список сообщений. Можно исправить файл и загрузить снова или перейти по ссылке «Вернуться к демонстрации».

Ограничение размера: **2 МиБ**. Кодировка файла — **UTF-8**.

Примеры лежат в `examples/valid/` (корректные) и `examples/invalid/` (для проверки отказов).

## Обозначения ролей

Подчёркивания согласованы со школьными обозначениями членов предложения:

| Роль | Линия |
|------|--------|
| Подлежащее | одна сплошная |
| Сказуемое | две сплошные |
| Определение | волнистая |
| Дополнение | штриховая |
| Обстоятельство | штрихпунктир (тире и точка) |
| Другая роль | серая сплошная |

Цвет усиливает различие, но форма линии остаётся основным признаком. Неразмеченные фрагменты текста отображаются без подчёркивания.

## Карточка слова

Щёлкните по размеченному слову в тексте. Откроется карточка:

- словоформа (как в исходном тексте);
- лемма, часть речи, синтаксическая роль, отношение;
- грамматические признаки (если есть в разметке);
- другие употребления в этом документе;
- блок словарной справки.

Пустые поля показываются как **«не указано»**, а не заполняются догадками.

## Поиск употреблений

В карточке два списка:

1. **По словоформе** — точное совпадение написания.
2. **По лемме** — если лемма есть в разметке; иначе подпись «Лемма в разметке отсутствует».

Результаты сгруппированы по синтаксической роли. Текущее слово в списки не входит. Если других вхождений нет — «Других употреблений нет». Щелчок по пункту выбирает слово в тексте и прокручивает к нему.

## Словарная справка

После выбора слова приложение запрашивает краткий фрагмент из **Русского Викисловаря**. Это не полная словарная статья.

Возможные состояния:

- текст справки и имя источника;
- «Справка временно недоступна» и ссылка «Искать во внешнем словаре»;
- загрузка («Загрузка справки…»).

Отказ сети или словаря **не мешает** просмотру текста, карточке и поиску употреблений.

## Что приложение не делает

- не строит синтаксический разбор «с нуля»;
- не хранит историю загрузок между сеансами;
- не требует учётной записи;
- не заменяет учебник или полный словарь.
