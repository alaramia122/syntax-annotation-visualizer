# Визуализатор синтаксической разметки

Веб-приложение для визуального представления **готовой** синтаксической разметки русскоязычных текстов и просмотра контекстной информации о словах.

> Приложение не выполняет самостоятельный синтаксический анализ. Оно принимает документ с текстом и разметкой, проверяет его, визуализирует результат и предоставляет поиск употреблений и словарную справку.

## Что реализовано

- загрузка JSON и демонстрационный документ при открытии;
- структурная (JSON Schema) и семантическая проверка;
- отображение исходного текста без потери пробелов, пунктуации и переносов;
- подчёркивания ролей по школьным правилам и легенда;
- карточка слова, поиск по словоформе и лемме с группировкой по ролям;
- справочный порт к Русскому Викисловарю (краткий фрагмент; отказ не ломает остальное);
- автоматические тесты и проверка через GitHub Actions.

## Быстрый старт

1. Python 3.10 или новее.
2. Виртуальное окружение и `python -m pip install -r requirements.txt`.
3. `python app.py` → `http://127.0.0.1:5000/`.
4. Тесты: `python -m pytest -q`.

Подробнее: [руководство пользователя](docs/user/USER_GUIDE.md).
