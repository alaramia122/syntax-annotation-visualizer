# Визуализатор синтаксической разметки

Веб-приложение для визуального представления **готовой** синтаксической разметки русскоязычных текстов и просмотра контекстной информации о словах.

> Приложение не выполняет самостоятельный синтаксический анализ. Оно принимает документ с текстом и разметкой, проверяет его, визуализирует результат и предоставляет функции поиска употреблений и словарной справки.

## Состояние проекта

На момент начальной настройки репозитория реализация ещё не добавлена. Требования и план разработки находятся в каталоге `docs/`. Текущая точка продолжения и ближайшие действия: [CURRENT_STATE.md](docs/development/CURRENT_STATE.md).

## Предусмотренные возможности

- загрузка JSON-документа и открытие демонстрационного примера;
- структурная и семантическая проверка входных данных;
- отображение исходного текста без потери пробелов, пунктуации и переносов строк;
- графическое обозначение синтаксических ролей преимущественно линиями под словами;
- интерактивная карточка слова;
- поиск по точной словоформе и по лемме, когда она доступна;
- группировка употреблений по синтаксическим ролям и переход к ним в тексте;
- необязательная словарная справка с указанием источника и корректной обработкой недоступности;
- автоматизированные тесты и проверка через GitHub Actions.

Это целевые требования, а не заявление о уже реализованной функциональности.

## Технологии

Предварительно предусмотрены Python 3, Flask, HTML, CSS, JavaScript, JSON, JSON Schema и pytest. Окончательный состав зависимостей фиксируется после архитектурного проектирования и проверки необходимости каждой зависимости.
