# Визуализатор синтаксической разметки

Веб-приложение для визуального представления **готовой** синтаксической разметки русскоязычных текстов и просмотра контекстной информации о словах.

> Приложение не выполняет самостоятельный синтаксический анализ. Оно принимает документ с текстом и разметкой, проверяет его, визуализирует результат и предоставляет функции поиска употреблений и словарной справки.

## Состояние проекта

Этап 1 закрыт: формат входных данных v1.0 описан, проверяется JSON Schema и семантическим валидатором, фикстуры имеют ожидаемые результаты. Подробности и журнал проверки — в [CURRENT_STATE.md](docs/development/CURRENT_STATE.md).

Проверено локально 2026-10-16 командой `python3 -m pytest -q` на Python 3.10.22: 33 passed. Этот локальный прогон не заменяет журнал GitHub Actions. Проверка интерфейса в браузере не выполнялась и не требуется для этапа 1.

Следующий этап плана — проектирование архитектуры.

## Предусмотренные возможности

- загрузка JSON-документа и открытие демонстрационного примера;
- структурная и семантическая проверка входных данных;
- отображение исходного текста без потери пробелов, пунктуации и переносов строк;
- графическое обозначение синтаксических ролей преимущественно линиями под словами;
- интерактивная карточка слова;
- поиск по точной словоформе и по лемме, когда она доступна;
- группировка употреблений по синтаксическим ролям и переход к ним в тексте;
- необязательная словарная справка с указанием источника и корректной обработкой недоступности;
- автоматизированные тесты и проверка через GitHub Actions.

Это целевые требования, а не заявление о уже реализованной функциональности.

## Технологии

Предварительно предусмотрены Python 3, Flask, HTML, CSS, JavaScript, JSON, JSON Schema и pytest. Для уже написанного кода зависимости перечислены в `requirements.txt` и `pyproject.toml`. Окончательное разделение модулей относится к этапу 2.

## Быстрый старт

1. Установите Python 3.10 или новее.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите приложение: `python app.py`.
5. Откройте `http://127.0.0.1:5000/` в браузере.

Запуск тестов: `python -m pytest -q`. Локальный результат 2026-10-16 приведён выше; он относится к дереву, в котором этот абзац зафиксирован, и не описывает будущие коммиты.
