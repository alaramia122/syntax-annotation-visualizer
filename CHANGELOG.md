# Журнал изменений

## 0.1.0 — 2026-10-17

Первый публикуемый снимок после этапов 1–11.

### Реализовано

- загрузка и проверка JSON (схема + семантика), лимит 2 МиБ;
- демонстрационный документ на `GET /`;
- визуализация текста с школьными подчёркиваниями ролей и легендой;
- карточка слова, употребления по словоформе и лемме с группировкой по ролям;
- справочный порт к Русскому Викисловарю (`GET /dictionary`);
- адаптивная вёрстка (узкий экран — одна колонка);
- автотесты (модульные, интеграционные, качественные); CI на Python 3.10–3.12.

### Ограничения

- нет собственного синтаксического анализа;
- справка — краткий extract, не полная статья;
- нет headless-тестов браузерного UI в CI.
